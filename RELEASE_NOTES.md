# v0.4.0b — подключение прежде всего

Телекон по умолчанию подключается к лекциям. Запись включается отдельно
в **Настройки → Запись → Записывать лекции** и применяется к следующей встрече.

## Что изменилось

- Полностью обновлён интерфейс: Liquid Glass + Material 3, светлые поверхности,
  фисташковые акценты и голубая палитра.
- Добавлены мягкие анимации окон, вкладок, новых карточек и сообщений.
  Уменьшение движения отключает эффекты, включая подложку диалога.
- Настройки разделены на **Основные**, **Запись** и **Уведомления**.
  Чекбоксы заменены тумблерами; кнопки сохранения остаются на виду.
- **Добавить лекцию (N)** и **Быстрое подключение (F)** находятся в основном
  ряду действий. Боковую панель можно свернуть.
- Сохранены MKV/MP4, качество, свои FPS от 1 до 60, разрешение в пределах
  монитора, шаблоны имени, фильтр коротких видео и подтверждённое удаление.
- Добавлены явные возможности платформ: Windows-функции записи и защиты от сна
  не мешают подключению в Linux/macOS.
- Подготовлены GitHub Actions для проверок PR и нативных сборок Windows x64,
  Linux x64, macOS Apple Silicon и Intel.
- README переписан для пользователей и дополнен реальными скриншотами.
  Добавлены руководство, CONTRIBUTING.md и форма сообщения об ошибке.
  Приветствуются исправления, в том числе с помощью ИИ.

## Установка и совместимость

Windows: распакуйте **весь архив** и запустите `Telecon.exe`.
Нужен Microsoft Edge WebView2 Runtime. Python и OBS отдельно не нужны.
Запись после обновления с v0.3.x нужно включить вручную; календарь,
аккаунт и ранее сохранённые видео остаются.

Linux/macOS пока экспериментальные: календарь, вход в Яндекс и подключение.
Запись, защита от сна и предупреждения о скрытом окне доступны в Windows.
Нативная сборка другой ОС считается проверенной только после успешного
запуска соответствующего workflow. CI-артефакты не публикуются в Releases
автоматически; macOS ad-hoc подпись не заменяет Developer ID/нотариализацию.

Версия сохранена **v0.4.0b**. Архивы создаются **без Hashsum**.
Результат проверки конкретной сборки находится в `SELF-CHECK.json`,
область проверки — в `BUILD-INFO.json`.
Проверено локально: 193 unit-теста, 3 UI-регрессии, полный UI smoke,
17/17 самопроверок Windows EXE и 4/4 portable-проверки этого же EXE.
После первого запуска CI исправлены упаковка ресурсов macOS и конфигурация
Qt/PySide6 в Linux. Исправления ожидают повторной нативной проверки в Actions.
Имена скачиваемых артефактов больше не содержат числовой ID запуска.
