# v0.3.0b — календарь и сохранение видео

- При удалении лекции можно выбрать: убрать только карточку из календаря или
  удалить её вместе с видеофайлом. Удаление файла требует подтверждения.
- В настройках появилась минимальная длительность видео. Значение `0` сохраняет
  записи любой длины; более короткие записи удаляются, а причина остаётся на карточке.
- Добавлены шаблоны имени файла и предварительный пример в настройках.
  Например, `{name}-{date}-{duration}` → `История_архитектуры-181026-85.mkv`.
- Доступны название, два формата даты, время начала и окончания, фактическая
  длительность в полных минутах. Если название непригодно, используется ID встречи;
  при ошибке шаблона файл сохраняется под ID встречи. Совпавшие имена получают суффикс.
- Кнопки **Добавить лекцию (N)** и **Быстрое подключение (F)** теперь находятся
  рядом над календарём. Дублирующие кнопки из боковой панели убраны.
- Боковую панель можно свернуть небольшой кнопкой в левом верхнем углу.
- Убраны технические подписи и повторяющиеся пометки на карточках.
- Повышена стабильность последовательных записей.

Существующие лекции и видео сохраняются. Видео старых версий, путь к которым
не был привязан к карточке, удаляются вручную из папки записей.
