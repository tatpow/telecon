# v0.4.1 — исправления сборок

- Linux: зафиксирована версия PySide6 и явно настроены пути Qt-плагинов.
- macOS: ресурсы перенесены в Contents/Resources перед подписью приложения;
  расположение Mach-O бинарников и пути загрузки данных сохраняются.
- Добавлены проверки переноса ресурсов и диагностические файлы при сбое CI.
- Из имён скачиваемых артефактов убран числовой ID запуска.
- Уточнено скачивание сборок: Actions → нужный запуск → Artifacts.
- Исправлена совместимость CSP с генератором JS-моста pywebview в Linux/macOS.
  Произвольные inline-скрипты, inline-стили и внешние скрипты остаются заблокированы.
- Добавлена браузерная регрессия CSP и дополнительные сведения о native UI при сбое.

- macOS: интерфейс загружается напрямую в WKWebView без локального HTTP-сервера.
  Стили и скрипты из поставки защищены индивидуальным CSP nonce.
- CI проверяет настоящее окно macOS до компиляции и после упаковки.
  При сбое сохраняются стадии загрузки и стеки потоков.

Локально проверены 203 unit-теста, 5 браузерных регрессий,
4/4 portable source checks на Windows в обычном и прямом HTML-режиме и actionlint. Нативные
Linux/macOS-сборки необходимо подтвердить новым запуском GitHub Actions.
Сборки выполняет автор через GitHub; файлы Hashsum не создаются.
