# Руководство пользователя

[← На главную](../README.md)

## Подключение и расписание

Для разового входа нажмите **Быстрое подключение** или **F**, вставьте
ссылку Телемоста и укажите время окончания. Телекон подключится сразу.

Чтобы запланировать встречу, нажмите **Добавить лекцию** или **N**.
Укажите название, ссылку, начало, окончание и время раннего входа.
Включите **Автоподключение** в боковой панели. В конце встречи Телекон
выйдет из неё. Одновременно приложение ведёт одну встречу.

Ссылки принимаются с `https://` и без него. Поддерживаются ссылки вида
`telemost.yandex.ru/j/…`. Для входа в аккаунт используется главная
страница Телемоста, а не заранее заданная встреча.

Поиск открывается клавишей **/**. Сочетания не срабатывают при вводе текста.
Кнопка сворачивания боковой панели остаётся доступна и после её закрытия.

## Основные настройки

**Длительность пары** задаёт окончание новых лекций и быстрого подключения.
По умолчанию это 90 минут. Уже добавленные лекции не меняются.

**Не давать компьютеру засыпать** работает в Windows, пока включено
расписание или идёт встреча. Параметры питания не изменяются; ручной сон,
закрытие крышки и блокировка системы не отменяются. В Linux и macOS
этой функции пока нет.

**Войти в Яндекс** открывает отдельный локальный профиль браузера.
После авторизации закройте браузер. Не запускайте настройку аккаунта
одновременно с расписанием или текущей встречей.

## Запись в Windows

По умолчанию запись выключена. Её тумблер находится во вкладке **Запись**.
Изменения применяются к следующей встрече.

| Настройка | Варианты |
|---|---|
| Формат | MKV по умолчанию или MP4 |
| Качество | Максимальное, сбалансированное, компактное, экономное |
| FPS | Готовые варианты и своё целое число от 1 до 60 |
| Разрешение | Авто, готовые размеры или свои чётные ширина и высота от 64 пикселей |
| Папка | По умолчанию **Видео/Telecon**, можно выбрать другую |
| Минимальная длительность | `0` отключает фильтр; больше `0` задаёт минимум в минутах |

Разрешение не может превышать монитор окна настроек. При начале встречи
оно дополнительно подстраивается под её монитор; пропорции сохраняются.
Режим «Авто» вписывает видео в 1920×1080 в пределах экрана.
Понижение качества, FPS и разрешения помогает уменьшить размер видео.

MKV используется как устойчивый промежуточный контейнер. При выборе MP4
готовая запись переносится в MP4 без повторного сжатия.
Если преобразование не удалось, исходный MKV сохраняется, а на карточке
появляется сообщение.

Видео короче установленного минимума не сохраняется, в том числе после
ручной остановки. Причина остаётся на карточке. Сравнение идёт по фактической
длительности: 4 минуты 59 секунд меньше порога 5 минут.

При сбое незавершённый файл может остаться для восстановления.
Приложение сообщает об ошибке и не выдаёт такую запись за успешно сохранённую.

## Имена файлов

Введите шаблон во вкладке записи. Предварительный просмотр показывает пример.

| Атрибут | Значение | Пример |
|---|---|---|
| `{name}` | Название лекции; пробелы заменяются на подчёркивания | `История_архитектуры` |
| `{date}` | Дата начала, ДДММГГ | `261026` |
| `{date_iso}` | Дата начала, ГГГГ-ММ-ДД | `2026-10-26` |
| `{time}` | Фактическое начало, ЧЧ-ММ | `09-00` |
| `{time_end}` | Фактическое окончание, ЧЧ-ММ | `10-25` |
| `{duration}` | Фактические целые минуты с округлением вниз | `85` |

Например, `{name}-{date}-{duration}` даст
`История_архитектуры-261026-85.mkv`.
Расширение выбранного формата добавляется автоматически.
Если имя занято, добавляется числовой суффикс.

Если название не подходит для имени файла, вместо `{name}` используется
идентификатор встречи. При ошибке в самом шаблоне он становится всем именем
файла. Подтверждать замену не нужно. Идентификаторы не являются атрибутами
шаблона; старый дублирующий `{длительность}` автоматически заменяется
на `{duration}`.

## Сворачивание и уведомления

Можно свернуть Телекон: подключение и работа продолжаются.
При сворачивании самого Телемоста во время записи изображение становится
чёрным, а звук встречи продолжает записываться. После разворачивания
изображение возвращается.

Во вкладке **Уведомления** отдельно включаются звук, уведомление Windows
и значок на иконке. Для звука есть громкость и предварительное прослушивание.
Предупреждение исчезает после восстановления окна встречи.
Блокировка Windows прерывает запись; приложение не отменяет блокировку.

## Удаление и личные данные

Корзина на карточке предлагает удалить только запись календаря либо
календарь и связанный видеофайл. Перед удалением нужно подтвердить выбор.
Если файл изменился, был заменён или недоступен, удаление с диска
отклоняется, а карточка сохраняется.

Данные находятся отдельно от исходников:

| Система | Календарь, настройки и профиль |
|---|---|
| Windows | `%LOCALAPPDATA%/LectureAssistant` |
| macOS | `~/Library/Application Support/LectureAssistant` |
| Linux | `${XDG_DATA_HOME:-~/.local/share}/LectureAssistant` |

Пароли вводятся на странице Яндекса в браузере. Не отправляйте папку профиля,
cookies, базу календаря и записи в публичный репозиторий или Issues.

## Не получается подключиться

Проверьте ссылку, время окончания и вход в Яндекс. Если интерфейс Телемоста
изменился, сохраните точный текст ошибки и
[сообщите о проблеме](https://github.com/tatpow/telecon/issues/new/choose).
Личные ссылки для этого не нужны.
