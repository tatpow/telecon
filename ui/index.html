НАСТРОЙКИ

Настройки

Используется для окончания новых лекций и быстрого подключения. Существующие лекции не меняются.

0 — сохранять видео любой длины. Более короткое видео удалится после завершения записи; причина останется на карточке.

Применяется к новым записям. Качество изображения и звука одинаковое.

Атрибуты имени файла
{name}
Название лекции, пробелы заменяются на _
{date}
Дата начала записи: ДДММГГ
{date_iso}
Дата начала записи: ГГГГ-ММ-ДД
{time}
Время начала: ЧЧ-ММ
{time_end}
Время окончания: ЧЧ-ММ
{duration}
Фактическая длительность в минутах, округлённая вниз

Расширение выбранного формата добавится автоматически. При непригодном названии используется ID встречи, при ошибке шаблона — имя файла из ID встречи. Совпавшие имена получают суффикс -2, -3 и далее.

Пока включено расписание или идёт запись. Параметры питания и блокировка Windows не меняются.

Предупреждение о свёрнутом Телемосте

Во время записи, один раз при каждом сворачивании окна встречи. Работает и при свёрнутом Телеконе.

После разворачивания окна встречи значок исчезнет. Громкость сигнала не меняет звук встречи или Windows.

Аккаунт Яндекса

Войдите корпоративным аккаунтом в открытом браузере, затем закройте его. Сессия останется в локальном профиле Телекона.

Перед входом приостановите расписание и завершите запись.

Сохранение видео

Записываем окно Телемоста и звук только его браузера. Другие приложения и микрофон в звуковую дорожку не включаются. Телекон можно свернуть. При сворачивании окна Телемоста запись продолжается с чёрным видео и звуком встречи; изображение вернётся после разворачивания.
