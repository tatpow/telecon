# Проверки v0.4.0b

Состояние на **25 октября 2026**. Версия в этой доработке не повышается.

## Проверено локально на Windows x64

- **193 unittest-теста**: успешно.
- **3 сохраняемых UI-регрессии** (`python tests/check_ui.py`): успешно.
  Этот же набор включён в Linux-job workflow Checks.
- UI smoke в настоящем Chromium на временной SQLite-базе: успешно.
  Проверены календарь, поиск, CRUD, быстрое подключение/остановка, вкладки,
  тумблеры, настройки качества/FPS/разрешения и отсутствие записи по умолчанию.
- Размеры окна: 1536×1024, 1220×820, 820×600 и 390×844.
  Кнопки сохранения доступны, горизонтального переполнения нет.
- Проверены вход/выход анимаций, быстрое закрытие и повторное открытие диалога,
  Escape и возврат фокуса, отсутствие повторной анимации неизменённых карточек.
  При reduced motion не запускаются JS/CSS-анимации и анимация backdrop.
- Настройки неподдерживаемых платформ проверены на подставленных возможностях:
  запись, звук предупреждения и защита от сна недоступны, основные настройки доступны.
  Это проверка поведения, не запуск Linux/macOS.
- Полная **самопроверка исходников: 17/17** — изображение/звук,
  сворачивание/восстановление, последовательные записи, MKV/MP4, 7/60 FPS,
  шаблоны, короткие видео, оба режима удаления, питание, уведомления,
  native WebView2 и подключение без захвата.
- **Portable smoke-check: 4/4** — временный календарь, режим подключения,
  настоящий Chromium и native UI/JS bridge.
- `node --check` для обоих JS-файлов и **actionlint 1.7.12**: успешно.
- Скриншоты README сняты с реального интерфейса на демонстрационных данных.
  Личные аккаунты, cookies, календари и пользовательские записи не использовались.

EXE: 17/17**, дополнительный **portable check готового EXE: 4/4**.
FileVersion и ProductVersion — `v0.4.0b`, числовая версия — `0.4.0.0`.
Предыдущий архив сохранён отдельно. Документация и реальные скриншоты включены
в новый архив. **Целостность ZIP подтверждена (CRC)**; в архиве 572 файла.

после успешного self-check. Файлы Hashsum и хеши исходников не добавляются.

## GitHub Actions и другие платформы

По предоставленным журналам первого запуска Windows собрался, Linux упал
при инициализации QtCore/поиске xcb, macOS arm64/x64 — на подписи данных
в Contents/MacOS. Внесены исправления: PySide6 6.9.3, явные пути Qt и перенос
ресурсов macOS перед подписью. **Повторные нативные сборки после исправления
ещё не проверены**. Успешный Windows-тест не подтверждает Linux/macOS.

Локально после исправления проходят **197 unittest-тестов** и actionlint.
Новые регрессии проверяют Qt-конфигурацию, перенос данных с сохранением
бинарников/ссылок, повторный вызов, отказ от перезаписи и выход за границы bundle.

- Checks: Ubuntu 24.04, Windows Server 2025, macOS 15 arm64 и Intel.
- Native builds: архивы Linux x64, Windows x64, macOS arm64/x64.
- Каждый готовый бинарник должен пройти native UI/browser smoke-check.
- Windows hosted CI имеет явно ограниченную проверку `portable`:
  `recording_checked: false`. Она не заменяет WGC/WASAPI-проверку на Windows 11.
- Linux/macOS не поддерживают запись, защиту от сна и предупреждения о скрытом окне.
- Ubuntu — CI-база; Linux Mint/Fedora инструкции требуют отдельной проверки.
- macOS ad-hoc подпись не является Developer ID или нотариализацией.

Команды и ограничения: [BUILDING.md](BUILDING.md).
Версии: CPython 3.12.10, pywebview 6.2.1, Playwright 1.63.0,
Nuitka 2.8.10, imageio-ffmpeg 0.6.0, windows-capture 2.0.1, proc-tap 1.1.1.
